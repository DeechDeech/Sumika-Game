推奨仕様は、512 x 512 px の正方形・RGBA透過背景・PNG形式です。果実を中央に配置し、画像の縦方向が果実の上下に合うよう作成してください。画像は物理円に沿って円形に切り抜かれるため、左右が見切れても問題ありません。転がり時の回転が見えるよう、ヘタや葉など上下が分かる形を含め、画像自体は正立状態で保存してください。ゲーム内では物理ボディの角度に合わせて回転し、半径に合わせて拡大縮小されます。

画像がまだない種類は、従来の色付き円で表示されます。
